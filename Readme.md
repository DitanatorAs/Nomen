# Десктопное приложение для учета номеклатуры

Позволяет автоматизировать процесс учета номенклатуры Котельно-промышленной компании.

## Перед запуском
Необходимо указать точные параметры для подключения к БД в файле **database.json**

## Для запуска 
Необходимо запустить файл **Main.rb**

# Desktop application for registration of nomenclature

It allows you to automate the process of accounting for the nomenclature of a boiler and industrial company.

**To run**, you need to run the main file: **Main.rb**
